# 上线前需要在微信后台完成的事项

代码里已经全部接好，下面这些只能在「微信公众平台 / 云开发控制台」里操作。

## 1. 用户隐私保护指引（不填过不了审）

公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引，勾选并说明用途：

| 信息 | 用途写法（可直接用） |
|---|---|
| 剪切板 | 用于导出和恢复你的记录备份 |
| 选中的文件 | 用于从聊天记录中选择备份文件恢复记录 |
| 位置信息 / 选择的位置 | 用于按宝宝所在地获取天气，给出穿衣建议 |
| 相册（仅写入） | 用于把今日卡片、一周小结保存到相册 |

小程序里已在每个页面挂了 `<privacy-popup />`，用户第一次用到上面任一能力时会弹出说明，同意后自动继续。

## 2. 类目

涉及「建议就医」「生长百分位」「喂养参考区间」等健康参考内容。提审时请确认类目；
文案已统一为「参考 / 建议问问医生」，`tools/check.js` 会拦截「确诊、治愈、一定是」等说法。

## 3. 数据埋点（可选，不做也不影响功能）

公众平台 → 数据分析 → 自定义分析 → 事件，按下表新建（事件名带 `xyd_` 前缀）：

| 事件 | 参数 | 含义 |
|---|---|---|
| xyd_baby_add | preterm | 添加宝宝 |
| xyd_care_log | type, via | 记喂奶/睡眠/尿布（via：timer 计时 / quick 快捷 / backfill 补记） |
| xyd_meal_log | via | 记一餐（suggest 推荐 / manual / copy 同上一餐） |
| xyd_food_try | — | 试新食材 |
| xyd_vax_log | via | 记接种（remind 首页提醒 / plan 规划表 / manual） |
| xyd_backup_export | method | 导出备份（file / clipboard） |
| xyd_backup_import | method, mode | 恢复备份（mode：merge / replace） |
| xyd_share_card | from | 分享卡片（daily / weekly / save / copy） |
| xyd_remind_tap | kind | 点提醒（vax / backup） |
| xyd_onboard_step | step | 首次引导（first / place） |
| xyd_sync_join | — | 加入家庭同步 |
| xyd_weekly_open | — | 打开一周小结 |

**只上报动作，不上报任何记录内容**（名字、时间、食材、颜色都不带），隐私指引里可以这样写。

## 4. 家庭同步（不开也能用，「我的 → 家庭同步」会显示暂不可用）

1. 开通云开发，把环境 ID 填进 `app.js` 的 `globalData.env`（留空则用默认环境）
2. 开发者工具里右键 `cloudfunctions/sync` → 上传并部署（云端安装依赖）
3. 云开发控制台 → 数据库：首次调用会自动建 3 个集合，权限都设为「仅云函数可读写」：
   - `xyd_families`：家庭、成员、数据清单
   - `xyd_family_parts`：按月分块存的记录（每块约 50–100KB）
   - `xyd_join_guard`：家庭码试错记录（同一微信 1 小时内最多试错 5 次）
4. 建议给 `xyd_family_parts` 的 `familyId` + `name` 建一个组合索引（清理旧块时用）
5. 同步按月分块、只传有变化的块，单次传输远低于云函数 1MB 上限，数据量不再有上限问题
6. 云函数超时建议调到 20 秒（首次加入家庭时要分批下载全部历史）

## 5. 订阅消息（推送给带娃人）

申请到模板 ID 后填进 `app.js` 的 `globalData.tmplIds`，首页推送卡会自动展开。
